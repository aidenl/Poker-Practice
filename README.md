# Preflop Drill

UTG와 UTG+1에서 8-handed No Limit Hold'em 오프닝 레이즈를 연습하는 반응형 웹 앱입니다.

## 실행

`index.html`을 PC 브라우저에서 열면 바로 사용할 수 있습니다.

## Android 앱으로 설치하기 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 예: `poker-preflop-drill`.
2. 이 폴더의 파일 전체를 새 저장소에 올리고 `master` 또는 `main` 브랜치에 푸시합니다.
3. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
4. **Actions** 탭의 `Deploy to GitHub Pages` 작업이 완료되면 표시되는 사이트 주소를 Android Chrome에서 엽니다.
5. Chrome 메뉴 `⋮`에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.

앱은 설치 후 전체 화면으로 열리며, 한 번 방문한 뒤에는 오프라인에서도 사용할 수 있습니다.

레이즈 범위는 제공된 차트의 파란색 영역을 기준으로 합니다: 모든 페어, AJs+, AQo+, KQs, QJs, JTs, T9s, 98s.
